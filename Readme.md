============================================
  ADDING NEW BLOG POSTS:
============================================

  Create a file in _posts/ named:
    YYYY-MM-DD-your-slug.md

  With this front matter:
    ---
    title: "Your Title"
    date: YYYY-MM-DD
    layout: post
    slug: your-slug
    ---
    Your content with **markdown** and $math$...

  Then: git add, commit, push. Done.
